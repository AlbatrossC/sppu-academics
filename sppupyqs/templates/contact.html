Best Ways to Report

  • Missing or wrong paper Include the branch, pattern, semester, subject name, and exam type.
  • Broken PDF or viewer issue Send the page URL and mention whether it happened on mobile or desktop.
  • Website bug or improvement Open a GitHub issue if one does not already exist.

For public bugs, duplicate reports, or feature requests, check existing issues first. If none exists, open a new issue in the repo.
